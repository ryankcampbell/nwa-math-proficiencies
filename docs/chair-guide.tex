\section*{Before Oct 21}
\begin{itemize}
\item Email the six teachers the Workshop link and the teacher's guide. Ask each to open it once
  (catches sign-in trouble early).
\item Print each course's proficiency list for the paper activity (public site $\to$ a course $\to$ print).
\item Sheet $\to$ \ui{Share}: teachers \emph{Viewer} or not listed (Sheet editors could change the script).
\end{itemize}

\section*{Oct 21 meeting run sheet (30 min)}
\begin{description}[style=sameline,leftmargin=3.3em,font=\color{teal}\bfseries]
\item[0:00] \textbf{Why.} Admin wants a scope \& sequence: themes across courses, one tab per area.
  Ours also lives online, permanently, and feeds summer practice.
\item[0:03] \textbf{Paper first.} Pairs with printed lists rotate every 3 min, naming threads that
  run through both courses. Collect them on the board.
\item[0:13] \textbf{Compare to the draft.} Project \ui{Scope \& Sequence}; walk two strands. Where the
  board and the draft disagree, write it down; that is Round 1's work.
\item[0:20] \textbf{Demo.} Home page, type \texttt{NWA26}; open a practice set, try the slider.
  Then the Workshop: move one proficiency, write one cell.
\item[0:26] \textbf{Assign the rounds} (below) and the dates.
\end{description}

\section*{Round 1: Sort (2 weeks)}
Each teacher owns their course: thread for every proficiency, wording, retire or add, and their
column's cell in every row. Strand stewards (optional) read one strand top to bottom for flow.

\section*{Round 2: Cross-check (2 weeks)}
Neighbor pairs work the \ui{Review} page together: 6--7, 8--IM1, IM2--IM3, IM3--PC/APC, APC--Calc.
Each overlap: \emph{Spiral}, \emph{Redundant} or \emph{Not the same}. Disagreements become questions.

\columnbreak
\section*{Your weekly 10 minutes}
\begin{enumerate}
\item Sheet $\to$ \emph{Changelog}: who has started, what changed.
\item Workshop $\to$ \ui{Review}: undecided overlaps and open questions. Nudge stragglers.
\item \ui{publish to public site} when the draft is in good shape (weekly is fine).
\end{enumerate}

\section*{November meeting}
\begin{enumerate}
\item \ui{Review}, filter \emph{Undecided}: settle what's left, decide each open question.
\item Scan each strand tab for empty cells or ``n/a'' that should not be.
\item Publish v1. Public site $\to$ \ui{Download Excel} (one tab per strand) for administration.
\end{enumerate}

\section*{Spring and summer}
\textbf{Resources:} aim for one per proficiency. Teachers add links in the Workshop or send you files;
save them in \texttt{deptchair/curriculum\_map/resources/} (private; links in \texttt{resources.md}).
\textbf{Practice bank:} ask Claude to mine that folder: it tags exam questions to codes, reports
coverage gaps, and writes \emph{new} problems (5 demo sets live now). Course teachers approve before
publishing. \textbf{May--June:} teachers make summer links and class codes.
\textbf{Each spring:} one revision round, same steps.

\section*{Upkeep}
\begin{itemize}
\item \textbf{Add or remove a teacher:} Config $\to$ editors (comma-separated; usernames are fine).
\item \textbf{Remove a resource:} delete its row in the \emph{Resources} tab, then publish.
\item \textbf{Edit collisions:} the later save wins; the Changelog keeps every version to copy back.
\item \textbf{GitHub token expires:} GitHub emails you. Make a new one (Contents read/write, this repo
  only) and paste it via \ui{NWA Math $\to$ Set GitHub token}.
\item \textbf{Health check:} add \texttt{?check=1} to the Workshop link.
\item \textbf{Code changes:} Claude updates the Workshop at the same link (needs \texttt{clasp login}).
\end{itemize}
